## 二、每天的操作顺序（重点）

### 第 0 步：启动系统

打开两个终端，都在项目根目录 `C:\Work\note\CursorWorkSpace\Professional-Investment`：

**终端 1（后端）：**

```bash
cd services/quant-api
uv run uvicorn app.main:app --host 127.0.0.1 --port 8010 --reload
```

**终端 2（前端）：**

```bash
cd apps/web
pnpm dev
```

然后浏览器打开：http://localhost:3010

> 嫌两个窗口麻烦？直接在项目根目录执行 `pnpm dev` 也可以同时启动前后端。

---

### 第 1 步：看仪表盘（首页）

打开 http://localhost:3010，先看一眼整体：

1. **账户总资产 / 组合回撤 / 现金比例 / 峰值利润率**：基于最新官方净值，每天早上开盘前就已确定。
2. **实时估算**：交易日盘中会显示今日盈亏（估算）和每只基金的估算涨跌，数据来自天天基金/新浪免费接口。
3. **持仓明细**：基于官方净值的精确持仓表，每天晚上净值公布后自动同步。

**刷新方式：**

- **白天想看盘中涨跌**：点“刷新估算”。
- **晚上 7–9 点净值公布后**：点“刷新净值”，官方总资产、持仓、日涨跌会同步为最新。

> 场外基金没有交易所那样的毫秒级实时价格，所以“实时估算”本质上是平台根据指数/ETF 走势估算的盘中净值，会和晚上公布的正式净值有偏差。正式净值以“刷新净值”后的数字为准。

---

### 第 2 步：更新净值并查看每日收益（每天可做）

首页仪表盘有 **"刷新估算"** 和 **"刷新净值"** 两个按钮：

- **交易日白天**：点 **"刷新估算"** 看盘中涨跌（基于免费估算接口）。
- **晚上 7–9 点净值公布后**：点 **"刷新净值"** 同步官方净值，总资产、持仓、日涨跌会更新为精确数字。

如果某只基金抓取失败，首页会提示失败代码，你再去「每周信号」页用 **"手动导入净值"** 补齐。

---

### 第 3 步：计算信号（每周一次，或你想下单前）

点击左侧导航 **每周信号** → 进入 `/signals`。

只在需要交易建议时执行：

1. 先点 **"1. 更新净值"**（如果首页已经刷新过，这里可以省略）。
2. 点 **"2. 计算信号"**。
3. 系统生成周报，告诉你：
   - **市场模式**：进攻 / 中性 / 利润保护 / 防守
   - **每只基金的评分、目标权重、建议动作**
   - **理由代码**：B1/B2/B3/B4 = 买入理由，S1/S2/S3/S4 = 卖出理由，P1/P2 = 减仓/锁定利润，N0 = 不动

动作一般分为三种：

| 动作 | 你应该做什么 |
|------|-------------|
| **BUY（买入）** | 按建议金额到支付宝/天天基金买入 |
| **SELL（卖出）** | 按建议份额到支付宝/天天基金卖出 |
| **HOLD（不动）** | 什么都不做，持有即可 |

> 建议金额/份额旁边有"死区"逻辑：如果金额小于 300 元或小于总资金的 1.5%，系统会建议不动，避免频繁小额交易。

**如果更新净值失败怎么办？**

- 回到同一页面，点 **"手动导入净值"** 按钮。
- 选择基金代码，按 `YYYY-MM-DD, 净值` 的格式粘贴，点确认导入。

**关于 589210**

`589210` 是 **广发科创芯片 ETF** 的场内代码。你的基金 `027521`（广发科创芯片设计 ETF 联接 C）成立时间较短，自身历史净值不够长，系统计算信号时会自动用 `589210` 的走势作为代理。如果自动抓取提示"589210 抓取失败"，你同样需要手动把它的收盘价导入系统——导入目标就选面板里的 **"589210 广发科创芯片ETF（027521 信号代理）"**。

> 简单说：027521 是你真正持有的基金；589210 只是帮它算信号的"替身"。你买卖还是按 027521 来。

---

### 第 4 步：AI 解读（可选但推荐）

如果你看不懂信号，点 **"AI 解读"**。

系统会把当周信号发给 LLM，返回三段中文：

1. **本周结论**：一句话总结该买、该卖还是持有。
2. **逐只基金解释**：每只基金为什么是这个动作。
3. **风险提示**：当前最大的风险点。

> AI 只解释系统已经算出的信号，不会自己决定买卖。买卖决策由规则引擎生成。

---

### 第 5 步：去销售平台下单

根据信号，在下一个开放日 15:00 前完成操作：

1. 打开支付宝 / 天天基金 / 银行 App。
2. 找到对应基金代码（001480、025343、005052、027521）。
3. 按系统建议买入或卖出。
4. **下单后保留成交截图**，下一步要用来录入系统。

> 系统不会自动帮你下单，它只给信号。真正的下单在你的场外销售平台完成。

---

### 第 6 步：回系统补录交易日志

成交确认后（通常是 T+1），点击左侧 **交易日志** → `/trades`。

按顺序录入每一笔：

| 字段 | 填法 |
|------|------|
| 日期 | 用**确认日期**（不是下单日期），截图里会写"确认时间" |
| 方向 | 买入 / 卖出 / 入金 / 出金 |
| 基金 | 买入/卖出时选对应基金代码 |
| 金额 | 实际扣款/到账金额 |
| 份额 | 确认份额 |
| 确认净值 | 截图里的"确认净值" |
| 费用估计 | 截图里的"手续费" |
| 理由代码 | 买入建议里会写，如 B1；首次建仓可填 B1 |
| 备注 | 可写"每周信号买入"或留空 |

录完后点 **记录**。

**查询某只基金的交易记录**：在页面下方"记录列表"右上角，用"筛选基金"下拉框选择基金代码，列表会只显示该基金；分页默认每页 20 条，记录多时翻页查看。

> 如果是入金或出金，不需要选基金、份额、净值，只填金额和日期。

---

> 左侧导航顺序已按使用频率排列：前两个（仪表盘、持仓与资金）每天看，后两个（每周信号、交易日志）按周或按交易需要看。

---

### 第 7 步：核对持仓与资金

点击左侧 **持仓与资金** → `/portfolio`。

这个页面只干一件事：告诉你 **哪些份额可以免费赎回，哪些还在赎回费窗口内**。

- 绿色行 = 赎回费率 0%，可以免费卖出。
- 红色行 = 仍在费用窗口内，现在卖出要扣赎回费。

如果你临时需要用钱或想减仓，优先卖绿色行的批次。

> 总资产、日涨跌、权重等日常数据已在仪表盘展示，本页不再重复。

## 三、不同场景下的操作

### 场景 A：每周五（常规信号日）

按完整顺序执行：启动 → 仪表盘 → 每周信号 → 更新净值 → 计算信号 → AI 解读 → 平台下单 → 次日补录交易 → 核对持仓。

### 场景 B：非交易日或没有信号

只看仪表盘和持仓，确认总资产没有异常即可。不需要操作。

### 场景 C：临时追加本金

1. 在交易日志录一笔 `入金`，日期用实际到账日，金额用实际金额。
2. 如果追加后当周信号仍有买入建议，可以按信号再买；如果没有，就等下周信号。

### 场景 D：需要临时卖出用钱

1. 优先卖出赎回费为 0 的批次（持仓与资金里绿色行）。
2. 在交易日志录一笔 `卖出`，份额和净值以平台确认单为准。
3. 如果卖出金额要离开投资账户，再录一笔 `出金`。

## 四、每月一次：复核权重

每月月底打开 **持仓与资金** 页面：

1. 看每只基金的「当前权重」和系统最近一次信号里的「目标权重」偏差是否超过 5%。
2. 如果偏差很大（例如某只基金从 20% 涨到 35%），等下周信号看是否会触发再平衡卖出（B4/S 类理由）。
3. 不要自己凭感觉调仓，让系统信号决定。

## 五、常见问题速查

### Q1：系统显示总资产和支付宝不一样？

- 检查交易日志里的份额、净值是否和支付宝确认单一致。
- 检查是否有重复或遗漏的交易。
- 检查入金金额是否为你的真实本金（系统之前有过 19044.07 的示例数据，已清理）。

### Q2：信号提示 BUY，但建议金额很小？

- 如果小于 300 元或小于总资金的 1.5%，系统会建议不动。这是正常设计，避免手续费侵蚀收益。

### Q3：净值更新失败，怎么手动补？

- 首页点 **"刷新净值"** 后，如果有基金抓取失败，会显示失败代码。
- 进入 **每周信号** 页面，点 **"手动导入净值"**。
- 选择失败基金代码（如果 027521 的信号代理 589210 失败，就选 589210）。
- 在文本框里按行粘贴，格式：`2026-08-07, 1.2345`。
- 点确认导入，系统会告诉你成功导入几条。

### Q4：为什么有的基金没有盘中估算？

盘中估算依赖数据源：

- 指数基金/ETF 联接基金：通常有估算。
- 主动管理基金：天天基金等平台不提供实时估算。
- QDII 基金（如 005052 摩根标普港股通低波红利）：受海外市场交易时间影响，A 股交易时段可能没有实时估算。

没有估算的基金卡片会显示“暂无估算”，晚上刷新净值后看正式日涨跌即可。

### Q5：交易日志里的"手续费"为什么很多是 0？

系统中"手续费"字段对应你截图里显示的申购/认购费用。当前四只基金里：

- `001480 财通成长优选混合 A`：A 类基金，买入时扣了一笔申购费，所以会显示具体金额（如 3.00 元）。
- `025343 / 027521 / 005052`：都是 C 类基金，买入时不收前端申购费，持有期间按日计提销售服务费（你已隐含在净值里，不会单独显示），所以系统里记为 0。

> 如果你截图里某笔买入显示了"手续费 0.00"，系统就填 0；如果显示了具体数字，就填那个数字。

### Q6：AI 解读报错？

- 进入 **设置** `/settings`。
- 检查 LLM 供应商、API Key、Base URL、模型是否填对。
- 点"获取模型列表"看能否拉取到模型。
- 多家供应商 Key 已支持独立保存，切换供应商时会自动恢复上次填的 Key。

### Q7：左边导航在手机上找不到？

- 屏幕宽度小于 768px 时，左侧边栏会变成顶部横向滚动导航，左右滑动即可。

## 七、一句话总结

> **交易日白天**：打开仪表盘 → 点 **"刷新估算"** → 看盘中涨跌。  
> **每天晚上**：打开仪表盘 → 点 **"刷新净值"** → 看正式收益和总资产。  
> **每周五（或想下单前）**：去每周信号 → 更新净值 → 计算信号 → 看 AI 解读 → 平台下单 → 成交后回系统补录 → 核对持仓。
