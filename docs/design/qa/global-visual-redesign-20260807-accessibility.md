# Accessibility Evidence: global-visual-redesign-20260807

## Checks Performed

1. **键盘可访问性**
   - 边栏导航为 `<a>` 链接，原生 Tab 可达；当前页带 `aria-current="page"`。
   - 所有按钮、输入框、下拉框为标准控件；供应商卡片为 `<button>`。

2. **对比度**
   - 买入红 `#B91C1C`、卖出绿 `#15803D`、主蓝 `#0B3868` 与白色文字对比度均 >4.5:1。
   - 次要文字 `#52616B` on `#F8FAFC` ≈ 5.4:1。
   - 闸门药丸、警示面板均带图标 + 文字，不单独依赖颜色。

3. **语义与非颜色线索**
   - 买/卖/入金/出金徽标均含中文文字。
   - 回撤/利润率警示除颜色外无独立含义依赖（阈值说明文字常驻）。

4. **响应式**
   - <768px：边栏折叠为顶部横向滚动导航；KPI 网格 4→2→1；信号操作按钮自动换行。

## Result

全站升级满足 WCAG 2.1 AA 基本要求，无已知无障碍阻塞项。
