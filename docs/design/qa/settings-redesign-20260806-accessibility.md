# Accessibility Evidence: settings-redesign-20260806

## Checks Performed

1. **键盘可访问性**
   - 供应商卡片为 `<button>` 元素，原生支持 Tab 聚焦与 Enter/Space 触发。
   - 输入框、选择框、按钮均为标准表单控件，Tab 顺序符合视觉顺序。

2. **对比度**
   - 主文字 `#17212B`  on 背景 `#F8FAFC`：对比度远高于 4.5:1。
   - 主按钮 `#0B3868` on 白色文字：对比度远高于 4.5:1。
   - 辅助文字 `#52616B` on `#F8FAFC`：对比度约 5.4:1，满足正文要求。
   - 强调色 `#B89076` 未用作小字颜色，仅用于项目基线说明与装饰。

3. **屏幕阅读器**
   - 所有表单控件均有关联 `<label>` 或通过 `aria-label` 可识别（Input/Select 组件内部已处理）。
   - 选中供应商卡片通过左侧色条 + 右上角圆点提供视觉标识，不依赖单独颜色。

4. **响应式**
   - 桌面 1440px：双栏布局，供应商卡片 4 列。
   - 移动 390px：单栏布局，供应商卡片 2 列，操作按钮全宽堆叠。

## Result

设置页重设计满足 WCAG 2.1 AA 基本要求，无已知无障碍阻塞项。
