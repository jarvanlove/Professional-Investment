# Design RFC: 全站视觉升级（深海铜·投资工作台）

## Status

Approved（用户于 2026-08-07 对话中确认：左侧边栏导航 + 红买绿卖 + 沿用 prussian-copper 基线）

## Problem

当前五个页面（仪表盘、每周信号、交易日志、持仓与资金、设置）视觉风格简陋：

- 顶部导航为一行裸链接，无当前页高亮、无品牌标识；
- 各页页头只有一行 `<h1>`，无说明、无层次；
- 仪表盘图表使用与基线无关的随手蓝色（`#2563eb`/`#93c5fd`）；
- 每周信号页闸门用 ✅❌ emoji，买卖徽标为美式绿买红卖；
- 交易日志与持仓页为裸表单 + 裸表格，无视觉层级。

用户反馈"整个系统的页面都不好看，像毛坯"。

## Evidence

- 用户截图反馈（2026-08-06）：设置页与其他页宽度不一致、风格简陋；
- 用户文字反馈（2026-08-07）："整个系统的页面做的都不好看"；
- 已批准基线：`docs/design/UI_VISUAL_BASELINE.json`（prussian-copper / 深海铜）；
- 设置页重设计（settings-redesign-20260806，已关闭）验证了基线在卡片/表单/选中态上的落地方式。

## Proposed Decision

在不改变 prussian-copper 视觉基线的前提下，进行全站布局与组件升级：

1. **全局骨架**：顶部裸导航改为左侧 200px 边栏（品牌区「规则化投资」+ 带 lucide 图标的导航项 + 当前页高亮），内容区保持 `p-8` 全宽。
2. **统一页头**：新增 `PageHeader` 组件（图标 + 标题 + 一句话说明 + 右侧操作区），五页统一使用。
3. **语义色**：新增买入红（`#B91C1C`）/卖出绿（`#15803D`）语义 token，遵循国内红买绿卖习惯；`buy`/`sell`/`deposit`/`withdraw` 徽标统一。
4. **数字规范**：金额与百分比使用 `tabular-nums` 等宽数字、千分位、右对齐。
5. **页面级改造**：
   - 仪表盘：KPI 卡加图标与主色左边条，回撤/峰值利润率超阈值变警示色；权重图收进卡片，配色改为基线蓝 `#0B3868` + 铜 `#B89076`。
   - 每周信号：顶部模式横幅（进攻/中性/利润保护/防守四色）；步骤条改为连贯 chevron；决策卡闸门改为「通过/拦截」药丸；警示说明收进琥珀色面板。
   - 交易日志：方向彩色徽标；金额右对齐；表格悬浮行。
   - 持仓与资金：现金/净投入/总资产升级为 KPI 卡；基金卡片加权重进度条；赎回费窗口内批次红色调行高亮。
   - 设置页：适配边栏骨架，视觉不变（上轮已按基线实现）。

## Alternatives Considered

- **顶部导航精修**：改动更小，但宽屏下内容区松散，且不像专业投资工具；用户已在对比中选择左侧边栏。
- **绿买红卖（美式）**：当前实现即此方案，但用户为国内基金投资者，红买绿卖更直观；用户已确认。
- **更换视觉方向**：设置页基线刚批准，全站更换方向将推翻已完成工作，无必要。

## System Impact

- Tokens:`globals.css` 新增 `--buy`/`--sell` 语义色；不改变已批准的 primary/accent。
- Components:新增 `AppShell`（边栏骨架）、`PageHeader`；改造 `StatCard`（图标 + 左边条）、`DecisionCard`（语义徽标 + 闸门药丸）、`WeightChart`（基线色）。
- Patterns:页头模式、KPI 卡模式、语义徽标模式、进度条模式，后续页面必须复用。
- Responsive behavior:边栏在 <768px 折叠为顶部横向滚动导航；KPI 网格 4→2→1 列。
- Accessibility:导航当前页用 `aria-current="page"`；徽标不单独依赖颜色（均带文字）；新增红/绿与文字对比度均 >4.5:1。
- Performance:无新增依赖；lucide-react 已在依赖中。
- Skill and evaluation rules:不引入新 UI Skill；沿用项目 UI 治理流程。

## Migration

一次性替换 `layout.tsx` 顶部导航为边栏骨架，逐页改造；无数据迁移；无 API 变更。
